Funciones principales

Una app pensada para la rutina real de un grupo fijo.

No intenta ser una red social ni un marcador genérico. Resuelve justo lo que hace falta para registrar partidos, revisar resultados y entender cómo evoluciona cada jugador con el paso del tiempo.

Nuevo partido en segundos

Selecciona la fecha, elige los jugadores habituales o añade uno nuevo, y deja preparada la sesión antes de empezar a jugar.

Historial filtrable por calendario

Revisa todo lo jugado con una lista clara y un filtro de fechas integrado que permite ir directo a cualquier día con actividad.

Clasificación automática

Cada set alimenta una clasificación visual por ratio de victorias para entender de un vistazo cómo quedó la jornada.

Estadísticas por jugador

La app muestra partidos, sets, victorias y ratio total, con mini gráficas y vistas de detalle para seguir la evolución individual.

Comparativa global del grupo

Un gráfico general cruza la trayectoria de todos los jugadores para ver tendencias, rachas y diferencias reales entre sesiones.

Backup y restauración en JSON

Exporta todo el contenido del grupo a un archivo compartible y vuelve a importarlo cuando cambies de móvil o quieras recuperar tus datos.
